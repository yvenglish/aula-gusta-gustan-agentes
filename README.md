# La tercera persona — Gusta y gustan

Página estática da YV Español preparada para GitHub Pages.

Inclui continuação da história, gramática, sete vídeos locais com revelação progressiva de legenda/tradução, atividades e formulário Web3Forms.

## Publicação

Extraia o ZIP e envie todo o conteúdo da pasta ao repositório. O arquivo inicial é `index.html`.
